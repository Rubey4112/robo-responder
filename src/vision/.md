# Roboguide Vision Package

This package houses the computer vision, camera capture, directional positioning, and live streaming subsystems for the Roboguide emergency responder robot.

## Modules

- **`stream_pipeline.py`**: Pipeline coordinating real-time camera capture, WebSocket server, Gemini Robotics ER 2 Live API, and HUD overlay.
- **`gemini_live.py`**: Bidirectional Live API client for `gemini-robotics-er-2-streaming-preview` with BLOCKING robotics tools.
- **`websocket_streamer.py`**: Asynchronous WebSocket server broadcasting video frames, telemetry, and robot directives.
- **`imaging.py`**: OpenCV photo capture, interactive camera HUD, burst capture.
- **`directional_positioning.py`**: Line & exit tracking with contour analysis and steering state calculation.
- **`STREAMING.md`**: Detailed technical architecture and WebSocket protocol specification.

## Quickstart

```bash
# Streaming mode (WebSockets + Gemini Robotics ER 2 Live API)
python -m src.vision --app stream

# Offline simulation mode
python -m src.vision --app stream --mock-gemini
```
